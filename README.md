## 🚀 Yo, What Is This Even?

**Roll Republik** isn’t your average roll shop app. It’s a hyper-aesthetic, neo-brutalist, ultra-fast **Kolkata Style Street Kathi Roll × Gen-Z Lab** experience built for hostel midnight cravings, study grinds, and campus foodies.

No 50-step setups. No clunky corporate UI. Just pure speed, spicy drops, live tawa telemetry, and a customizable monster roll sandbox that lets you flex your culinary rizz. 🌯🔥

---

## ✨ Features That Hit Different 😮‍💨

### 1. 🔥 Menu & Daily Drops
- **Curated Rolls**: Double Chicken Tikka, Triple Cheese Paneer Makhani, Kolkata Street Fusion, and nuclear Ghost Pepper rolls.
- **Heat Spectrum**: Filter from *Mild 😊* to *Nuclear 💥* (waiver required, no cap).
- **Secret Dips Add-on**: Smoked Garlic Aioli, Naga Ghost Crunch, Kolkata Kasundi, and Avo Crema.
- **Live Search**: Instant lookup across rolls, spice levels, and secret sauces.

### 2. 🧪 Custom Roll Lab 2.0 (The Sandbox)
- **Interactive Stacking Visualizer**: Watch your roll get layered in real-time — Base Wrap ➔ Protein Filling ➔ Crunchy Greens ➔ Double Sauce Drizzle ➔ Seasoning Dust.
- **Live Macro Engine**: Auto-computes **Kcal, Protein (g), Carbs (g), and Fats (g)** on the fly. Fitness bros ate and left no crumbs.
- **Custom Name Your Creation**: Crown your masterpiece (*"Midnight Boss Roll"*), save it, and drop it straight into your basket.
- **Community Formulas**: 1-click load top-voted presets like *"The Midnight Stuffed Beast"* by `@arjun_rolls`.

### 3. 🌙 Midnight Munchies Protocol (11 PM - 4 AM)
- **Live Countdown Clock**: Ticking down the late-night ordering window.
- **Dorm Party & Study Combos**: Big boy sharing boxes engineered for all-nighters.
- **Emergency Munchie**: Post-party revitalizer kit dispatched under 20 mins.
- **Kulhad Chai Flasks**: Kadak ginger chai piping hot for 90 mins.

### 4. 🛰️ Live Order Tracker & Kitchen Telemetry
- **Tawa Telemetry**: Follow the 4-stage cooking pipeline (*Marinated ➔ Live Charcoal ➔ Laccha Wrap ➔ Rider Out*).
- **Live Kitchen Cam (Cam 02)**: Peek straight at the 395°C tawa woks firing live.
- **Direct Chef Ping**: Send instant custom instructions (*"Bhaiya extra sirka pyaz please"*).
- **Rider Beacon**: View rider details, bike stats, and 1-tap direct call.

### 5. ⚡ Republik Rewards VIP Club
- **Level 4 Sauce God Tier**: Track your Roll Coins balance and unlock permanent perks.
- **Campus Checkout**: Express dorm delivery point selector, promo codes (`REPUBLIK50`), and UPI / GPay one-tap billing.

## ⚡ How to Run (Zero Friction)

### 💻 Option 1: Instant 1-Click Launch (No Node needed!)
Literally just double-click:
```
run-app.bat
```
...or double click `index.html`. It boots straight into your browser with zero dependencies installed.

### 🌐 Option 2: Run on Localhost Server
Wanna preview it on `http://localhost:3000/`? Run our lightweight script:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Then pull up `http://localhost:3000/` and enjoy the feast.

### 🛠️ Option 3: Vite Dev Server (For the Dev Nerds)
```bash
# Install dependencies
npm install

# Spin up Vite dev server
npm run dev
```
